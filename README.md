# 📚 Mini Guia de Direito Previdenciário com NotebookLM

Projeto desenvolvido para estudo e construção de portfólio, utilizando Inteligência Artificial como ferramenta de apoio à aprendizagem em Direito Previdenciário.

## 🎯 Objetivo

Criar um mini guia de estudo a partir de fontes jurídicas selecionadas, utilizando o NotebookLM para organizar informações, elaborar perguntas e apoiar a revisão dos conteúdos.

> **Importante:** a IA é utilizada como ferramenta de estudo. A conferência do conteúdo deve ser feita nas fontes jurídicas oficiais e na legislação vigente.

## 🧠 Problema

O Direito Previdenciário possui grande quantidade de legislação, conceitos, requisitos e alterações normativas. O projeto busca demonstrar como uma ferramenta de IA pode ajudar o estudante a organizar esse conhecimento sem substituir a consulta às fontes originais.

## 🛠️ Ferramentas

- NotebookLM
- GitHub
- Markdown
- Inteligência Artificial Generativa
- Legislação e fontes jurídicas oficiais

## 📖 Conteúdos estudados

O guia foi estruturado para abordar, entre outros temas:

- Seguridade Social;
- Saúde, Previdência e Assistência Social;
- Regime Geral de Previdência Social;
- Benefícios previdenciários;
- Qualidade de segurado;
- Carência;
- Tempo de contribuição;
- Aposentadorias;
- Benefícios por incapacidade;
- Dependentes e pensão por morte;
- Assistência Social e BPC;
- Principais conceitos utilizados na preparação para concursos.

## 🤖 Uso do NotebookLM

O NotebookLM pode ser utilizado para:

1. Reunir fontes previamente selecionadas;
2. Fazer perguntas sobre o material fornecido;
3. Produzir resumos para revisão;
4. Identificar conceitos importantes;
5. Criar perguntas de estudo;
6. Comparar conceitos presentes nas fontes;
7. Apoiar a elaboração do mini guia.

## 🔎 Metodologia

**Fonte → pergunta → resposta da IA → conferência → síntese → revisão.**

A etapa de conferência é fundamental para evitar que uma resposta gerada pela IA seja tratada como fonte jurídica.

## 📌 Resultado esperado

Ao final, o projeto deve funcionar como um material de revisão rápida para estudantes de Direito Previdenciário e candidatos a concursos públicos.
